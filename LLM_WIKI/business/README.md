# Для агента-менеджера / помощника CEO

Владелец планирует агента, который помогает управлять Ulya VPN как бизнесом: цифры, приоритеты, задачи для других агентов.
Эта страница — точка входа для него. Технические страницы читать не обязательно, но [gotchas.md](../gotchas.md)
полезен, чтобы понимать риски изменений.

## Как устроен бизнес (что известно)

- Продукт: подписка на VPN, продаётся в Telegram-боте; есть веб-кабинет и мобильное приложение ([../overview.md](../overview.md)).
- Деньги: пользователь пополняет баланс (~15 платёжек, Telegram Stars, крипта), с баланса покупает/продлевает подписку.
  Есть автоплатёж, триал, промокоды, реферальная программа с выводом, промо-группы со скидками, кампании.
- Удержание: напоминания о продлении (тихие часы), 3 дня резервного доступа после истечения
  ([../features/reserve-grace.md](../features/reserve-grace.md)), скидки после истечения.
- Расходы: серверы (VPS) и реклама, вносятся вручную в боте ([../features/admin-analytics.md](../features/admin-analytics.md)).

## Где брать цифры (по убыванию удобства)

1. **Google Sheets владельца** — обновляется каждую ночь в 03:00: транзакции, по месяцам, метрики (MRR, активные платящие,
   новые, отток, маржа), по тарифам, когорты, retention. Доступ к таблице у агента пока не настроен.
2. **Отчёты в админке бота** — дневной/недельный/месячный (`reporting_service`).
3. **БД напрямую** (только чтение и только с разрешения владельца): таблицы `transactions` (деньги в копейках,
   реальные поступления = `payment_method IN REAL_PAYMENT_METHODS`), `subscriptions`, `users`, `tariffs`,
   `subscription_conversions` (триал → платная), `referral_earnings`, `manual_expenses`, `infrastructure_servers`.
   Логику подсчёта метрик бери из `bot/export/sheets_sync.py`, чтобы цифры совпадали с таблицей.

## Как агенту-менеджеру работать с другими агентами

- Задачи на код ставятся отдельным агентам; каждое изменение — ветка от `staging` и PR в `staging` ([../workflow.md](../workflow.md)).
- Прод, деньги, рассылки пользователям, цены — только с явного «да» владельца.
- Решения владельца фиксируй в [../decisions.md](../decisions.md), незакрытые вопросы — в [../open-questions.md](../open-questions.md).
- Текущие инициативы: [initiatives.md](initiatives.md).

## Чего пока не хватает (раздел «Бизнес» в [../open-questions.md](../open-questions.md))

Цели и KPI владельца, каналы привлечения и CAC, состав команды, доступ к Google Sheets для агента.
