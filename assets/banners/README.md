# Баннеры разделов бота

Положите сюда картинку с именем ключа раздела, и бот начнёт показывать её на экранах этого раздела. Пока файла нет, показывается обычный логотип (`vpn_logo.png`). Новый файл подхватывается без перезапуска; если заменили уже показанный баннер под тем же именем, перезапустите бота.

Форматы: `.png`, `.jpg`, `.jpeg`, `.webp`. Размер как у текущего баннера: широкий, примерно 2:1 (например 1280×640).

| Файл | Раздел |
| --- | --- |
| `main.png` | Главное меню (/start, «Назад») |
| `subscription.png` | «Моя подписка», устройства, настройки |
| `buy.png` | Покупка: тарифы, выбор периода |
| `renew.png` | Продление |
| `trial.png` | Пробный период |
| `connect.png` | Подключение и инструкции |
| `balance.png` | Баланс и история |
| `payment.png` | Пополнение, выбор способа оплаты |
| `referral.png` | «Пригласить друга» |
| `support.png` | Поддержка и тикеты |
| `info.png` | «Инфо», правила, FAQ, язык, промокод |

Какие кнопки ведут в какой раздел, задано в `app/utils/banners.py`.
